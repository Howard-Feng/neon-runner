# 霓虹酷跑 · 3D（Neon Runner）

一个基于 Three.js 的 3D 无限跑酷小游戏，赛博霓虹风格，单文件游戏本体，打开即玩。

## 开始游玩

双击 `index.html` 用浏览器打开即可开始游戏，无需安装、无需联网。

> `three.min.js` 是 Three.js r160 官方库文件，需与 `index.html` 放在同一目录。
> 如果只想保留一个文件，也可以把 `index.html` 中的
> `<script src="three.min.js"></script>` 换成 CDN 地址：
> `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js`（这种方式需要联网）。

## 操作方式

| 按键 | 操作 |
|------|------|
| ← → / A D | 左右变道 |
| 空格 / ↑ / W | 跳跃（可二段跳） |
| ↓ / S | 下滑穿门 |
| P / Esc | 暂停游戏 |
| R | 快速重开 |

手机端可直接滑动屏幕，或使用屏幕底部的虚拟按钮。

## 游戏特色

- 三跑道无限赛道，速度随距离逐步提升（1～9 级）
- 三种障碍：路障、跨栏、光门，需要变道 / 跳跃 / 下滑分别应对
- 金币收集与连击加成，最高分保存在浏览器本地
- 精细建模的机器人角色：分段肢体关节动画、胸口能量核心、背包推进器、接触阴影
- 程序化生成的霓虹城市窗户、障碍警示纹理、落日光晕、粒子与速度线
- Web Audio 合成音效，无需外部音频文件

## 文件说明

- `index.html` — 游戏全部代码（HTML / CSS / JavaScript）
- `three.min.js` — Three.js r160 渲染库
